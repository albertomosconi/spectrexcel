Dalle misure ai file Excel

Scegli un flusso di lavoro, aggiungi i file dello strumento ed esporta un file Excel pronto per l'analisi. Puoi includere un foglio info con gli hash dei file sorgente, le impostazioni di analisi e i passaggi di elaborazione. Inizialmente è disattivato, ricorda l'ultima scelta e segue la lingua dell'app. Conserva gli input originali per la riproducibilità. Scopri i dettagli di esportazione.

Cinetica

.KD

Esporta le variazioni di assorbanza nel tempo, sottraendo l'assorbanza a una lunghezza d'onda di riferimento.

Legame

.SD / .txt

Confronta gli spettri di assorbanza di esperimenti di binding o titolazione ed esportali per ulteriori analisi.

Famiglia di spettri

.KD

Esporta gli spettri registrati nel tempo. I grafici mostrano uno spettro ogni due; le tabelle includono tutti gli spettri.

File dello strumento
.KD .SD .txt
File Excel
.xlsxTabelle delle misure e grafici di confronto.

Elabora le misure in locale. Mantieni privati i dati.

SpectrExcel funziona sul tuo computer: nessun account e nessun caricamento richiesto. I file delle misure restano sotto il tuo controllo e il progetto è open source.

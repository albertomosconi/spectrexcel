Elabora le misure in locale. Mantieni privati i dati.

SpectrExcel funziona sul tuo computer: nessun account e nessun caricamento richiesto. I file delle misure restano sotto il tuo controllo e il progetto è open source.

L'app contatta automaticamente GitHub all'avvio per verificare gli aggiornamenti e quando selezioni Verifica aggiornamenti. GitHub riceve le normali informazioni di connessione, inclusi l'indirizzo IP pubblico e le intestazioni della richiesta; i file delle misure non vengono inviati. Al momento non è possibile disattivare la verifica all'avvio dalle impostazioni. I download e i collegamenti al progetto richiesti vengono aperti nel browser. Consulta l'informativa su privacy e accesso alla rete e l'informativa sulla privacy di GitHub.

Trasforma i file dello spettrofotometro in cartelle di lavoro Excel strutturate.

SpectrExcel trasforma i dati grezzi dello strumento in report pronti per l'analisi in pochi clic.

Dalle misure alle cartelle di lavoro

Scegli un flusso di lavoro, aggiungi i file dello strumento ed esporta una cartella pronta per l'analisi.

Cinetica

Organizza le misure in serie temporale ed esporta i risultati cinetici calcolati.

Legame

Struttura le misure di titolazione per analizzare e confrontare il legame.

Famiglia di spettri

Raccogli spettri correlati in tabelle e grafici chiari dentro una sola cartella di lavoro.

Elabora le misure in locale. Mantieni privati i dati.

SpectrExcel funziona sul tuo computer. I file delle misure restano sotto il tuo controllo.

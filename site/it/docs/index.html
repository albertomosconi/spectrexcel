Guida utente di SpectrExcel

Installa l'applicazione desktop, seleziona un assay e trasforma i file spettrofotometrici supportati in una cartella di lavoro Excel.

Installazione

Windows

  1. Apri GitHub Releases e scarica spectrexcel-windows-x86_64.exe.
  2. Prima di avviarlo, verifica la provenienza del download e confronta il checksum con SHA256SUMS nella release.
  3. Avvia il file scaricato. Conferma un eventuale avviso del sistema operativo solo dopo avere completato queste verifiche.

Linux

  1. Apri GitHub Releases e scarica SpectrExcel-x86_64.AppImage.tar.gz.
  2. Estrai l'archivio, quindi avvia l'AppImage. L'archivio conserva il permesso di esecuzione.
  3. Assicurati che il sistema fornisca un'implementazione OpenGL X11/GLX funzionante e i driver grafici dell'host.

Se invece ottieni l'AppImage non archiviata, abilita il permesso di esecuzione prima di avviarla:

chmod +x SpectrExcel-x86_64.AppImage
./SpectrExcel-x86_64.AppImage

Crea la prima esportazione

  1. Avvia SpectrExcel.
  2. Seleziona l'assay adatto alla misura.
  3. Scegli il file o i file di input.
  4. Configura le opzioni mostrate per l'assay.
  5. Seleziona Genera Excel, scegli il file .xlsx di output e conferma l'esportazione.

L'area attività segnala il caricamento dei file, gli errori di validazione e le esportazioni completate.

Cinetiche

Usa cinetiche per seguire le variazioni di assorbanza nel tempo in una o più misure .KD.

  1. Seleziona uno o più file .KD. SpectrExcel li ordina inizialmente per nome con ordinamento naturale.
  2. Se necessario, usa Riordina file. Le colonne della cartella di lavoro e le tracce del grafico seguono questo ordine.
  3. Imposta la lunghezza d'onda di lettura e quella di correzione.
  4. Genera la cartella di lavoro Excel.

Per ogni istante, SpectrExcel sottrae l'assorbanza alla lunghezza d'onda di correzione da quella alla lunghezza d'onda di lettura. Il tempo parte da zero secondi e la cartella di lavoro contiene le tracce corrette e un grafico di confronto.

Binding / titolazione

Usa binding / titolazione per confrontare una serie di spettri di assorbanza contenuti in un file .SD o .txt.

  1. Seleziona un file di spettri.
  2. Imposta i valori minimo e massimo della lunghezza d'onda per l'asse X del grafico.
  3. Imposta i valori minimo e massimo dell'assorbanza per l'asse Y del grafico.
  4. Genera la cartella di lavoro Excel.

SpectrExcel rimuove i valori di deviazione standard. Se l'input contiene due metà identiche di spettri ripetuti, ne conserva una sola copia. La cartella di lavoro include i dati di lunghezza d'onda e assorbanza per ogni segnale e un grafico sovrapposto degli spettri con gli intervalli selezionati.

Famiglia di spettri

Usa famiglia di spettri per osservare come cambia uno spettro completo di assorbanza durante una misura cinetica.

  1. Seleziona un file .KD contenente spettri completi registrati a tempi di acquisizione successivi.
  2. Genera la cartella di lavoro Excel.

La cartella di lavoro contiene i tempi di acquisizione, le lunghezze d'onda e i valori di assorbanza di ogni spettro. Il grafico sovrapposto lunghezza d'onda-assorbanza mostra uno spettro ogni due per facilitare l'osservazione dell'andamento.

Formati dei file

  • .KD: misure cinetiche usate da cinetiche e famiglia di spettri.
  • .SD: spettri di assorbanza binari usati da binding / titolazione.
  • .txt: spettri di assorbanza testuali usati da binding / titolazione.

Sono supportati i file binari con intestazioni vecchie e nuove. Gli spettri coprono 190-1100 nm. I file devono comunque avere la struttura prevista per lo strumento e contenere dati di misura completi.

Risoluzione dei problemi

Input non supportato o danneggiato

Verifica che l'assay selezionato supporti l'estensione e che l'esportazione dello strumento sia completa. Un'intestazione illeggibile, spettri mancanti o una lunghezza d'onda selezionata non disponibile interrompono l'analisi o l'esportazione.

L'AppImage non si avvia su Linux

Per un'AppImage non archiviata, esegui chmod +x SpectrExcel-x86_64.AppImage. Se ancora non si avvia, verifica X11/GLX, OpenGL e i driver grafici dell'host.

Il selettore file non è disponibile su Linux

Installa Zenity o KDialog. SpectrExcel prova prima Zenity e poi KDialog; senza entrambi gli strumenti non può aprire il selettore file di sistema.

Verifica del download o dell'aggiornamento

Usa solo GitHub Releases. Confronta il file scaricato con i checksum pubblicati in SHA256SUMS prima di confermare un avviso del sistema operativo o sostituire un'installazione esistente.
